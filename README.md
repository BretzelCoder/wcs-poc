# PoC WCS — Warehouse Control System

Démo interactive d'un WCS : dispatching des commandes reçues du WMS, simulation d'AGV / convoyeurs / trieur, gestion des emplacements de stockage et interface WMS ↔ WCS simulée.

**Démo en ligne :** https://bretzelcoder.github.io/wcs-poc/
